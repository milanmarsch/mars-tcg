# Mars TCG Collection

The page visitors see when they scan the QR code on the Mars TCG table at card shows:
singles, slabs and selected sealed from CollectHolo (no prices; cards are stickered), plus the acrylic case price list.
Dutch and English.

- `index.html`: the page
- `data.json`: the collection (updated from CollectHolo before each show)
- `logo.jpg`: Mars TCG logo

Hosted with GitHub Pages: https://milanmarsch.github.io/mars-tcg/
